- **Sleek Light & Dark Mode**: Seamless toggle switch with system preference detection and localStorage persistence.
- **Dynamic Publication Filtering**:
  - Filter by **All (21)**, **Highlights**, **Preprints (4)**, or by **Year (2026, 2025, 2024)**.
  - Instant live keyword search bar (type "rheology", "chiral", "resetting", etc.).
  - Expandable, one-click copyable **BibTeX** citations.
  - High-impact badges for **Reviews of Modern Physics**, **Physical Review Letters**, and **PRE Editors' Suggestion**.
- **Impact Metrics Showcase**: Clean statistics counter for total citations (300+), h-index (9), and top-tier papers.
- **Research Pillars**: 4 rich visual overview cards for Active Matter Rheology, Dense Active Solids & Flocking, Stochastic Resetting, and Exact Analytical Dynamics.
- **Invited Talks & Presentations**: Chronological timeline covering 2022–2026 (APS Summit Denver, ISMC Goa, Colloquia).
- **International Collaborations Network**: Institutional network badges for US, India, Germany, Netherlands, and China.
- **Zero-Build Architecture**: Powered by modern HTML5, Tailwind CSS via CDN, and vanilla JS. No node/npm, Ruby, or Jekyll build errors—edit anywhere and it works immediately.
